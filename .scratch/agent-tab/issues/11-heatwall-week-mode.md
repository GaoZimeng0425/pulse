# 11: 日历图按周切换

**What to build:** 用户 2026-11-16「我希望日历图可以切换周,切换了以后每一列都是一周,
这一周都是同一个颜色,不同用量按周区分颜色,hover 上去是这一周的用量」。

**改动:**
- 日历图卡头药丸 06 的「年」占位单选 → 「天 / 周」粒度切换(子页内 state,默认天)。
- 按周:一列(连续 7 天,末列以今天收尾)同色,四档按周峰值归一,今天那份照旧折算全天。
- 悬停命中整列:描边整列外包框,浮层侧放(列右侧,放不下翻左),标题日期区间,读数周合计。
- 页脚峰值随档:「最多一天」/「最多一周」。
- PulseCore 新 `AgentHeatScale`(色阶量化、按周聚合、今天折算,自视图收进包)+ 8 测试;
  `ChartHoverGeometry.sideTooltipOrigin` + 3 测试。

**验收:** 起 app → 智能体 → 消耗 → 日历图卡头点「周」:每列一色;悬停一列整列描边,
旁边浮层「11月1日 – 11月7日 / X tokens」;页脚变「最多一周」。

**取舍(已向用户说明):** 周 = 现有列结构的滚动 7 天,不是周一到周日的自然周。
