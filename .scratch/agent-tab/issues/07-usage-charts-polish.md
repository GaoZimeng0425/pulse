# 07: 消耗子页两图根因修正 + 浮层 / 重扫按钮收编 + 项目卡重设计

**What to build:** 用户 2026-11-14 实报一揽子:「两个 chart 用起来别扭」「重新扫描
按钮不符合设计规范」「tooltip 不好看」「折线画线漂移、坐标偏、左侧没对齐边缘」
「折线要带背景,上浓下淡」「两个 chart 1280 变一列」「项目卡丑」。

**根因(折线别扭的真正来源,06g/06h 两次只绕症状):**

1. `LineMark(x: .value(_, date, unit: .day))` 带 unit → Charts 把点画在当天区间
   **中点 +12h**,而轴刻度、悬停吸附按零点;旧域 first−12h…last+12h 让首点离左缘
   一整天 = 「左侧没对齐」。→ 去 unit,域 = 首…末日零点。
2. 悬停把 overlay 本地坐标(含左 y 轴标签区)直接喂 `proxy.value(atX:)`,而它吃
   **绘图区坐标** → 系统性右偏 ≈ y 标签宽。→ 先减 plotFrame 原点。
3. 30 天 x 标签 `rotationEffect(-45°)` 不参与布局 → 斜字照样互压、伸出图外。
   → 每天一刻度保留,标签按宽抽稀横排(从今天倒数,末点恒标);Charts 日期标签
   默认左锚会把末签挤出图外被丢弃 → 中间居中、首左末右锚。
4. 双列判定 `ViewThatFits` 按弹性子视图理想宽,切换点不可控 → 显式断点。

  (`AgentUsageViews.swift` 1090 → ~450 行)。

- 热力墙:浮层锚定命中格上方(不再随光标像素抖)。
- 共用浮层 `AgentChartTooltip`:两行(日期含周几/今天 + 色块读数),系统材质底。
- 「重新扫描」→ 卡头文字按钮配方(arrow.clockwise + 文字,borderless 12 semibold
  secondary),与空间地图「在 Finder 中显示」同款。
- 日历图 + 走势:内容宽 ≥ 1232(窗宽 1280)两列等高,否则一列;单列走势定高 180
  (弹窗 120)。

  `{layout.agent-trend-height}` 180/120;走势 / 热力墙 / 浮层 / 项目卡条目改写。
