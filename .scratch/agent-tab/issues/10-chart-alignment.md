# 10: 日历图与走势同高、日期轴水平对齐

**What to build:** 用户 2026-11-15 实报「两个 chart 高度应该一致,左右的坐标应该是
水平位置对齐的」。07 并排靠 fixedSize 把两卡拉等高,但图区高各算各的(热力墙按宽
等比、走势弹性吃满),日期标签一边是自绘 Canvas、一边是 Charts 轴,基线不在一条线。

**改动:**
- 新 `AgentChartAxis`:两图共用的 18pt 日期轴带 + 唯一标签绘制函数(中线距图区底 11)。
- `AgentHeatWall.gridHeight(forWidth:)` 静态化;走势绘图区高套同式(同宽 → 同高),
  一列 / 两列都成立;弹窗紧凑档定高 100。
- 走势:隐藏 Charts x 轴,日期标签走 `AgentChartAxis` 自绘;y 标签挪进图内左上,
  绘图区铺满卡宽(左右缘与热力墙齐);图区底同热力墙 primary 6% 圆角 8;补页脚。
- 热力墙月签相邻 < 32pt 丢前一个(修「11月12月」挤一起)。

**验收:** 起 app → 智能体 → 消耗:≥1280 两图并排,两个图区上下缘、日期标签、
页脚三行逐行齐平;<1280 上下排时两图区同高、左右缘齐。
