# 01: 清理页两处空态文案指向已不存在的「空间地图」子页

**What to build:** 清理页未扫描时的两处空态说明写着「进度在「空间地图」子页」。空间
地图已经迁到磁盘页,清理页没有这个子页了,这句话把用户指向一个找不到的地方。改成
指向现在的位置。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

## Agent Brief

**Category:** bug

**Summary:** 两处用户可见的空态说明引用了已迁走的子页,更新文案。

**Current behavior:**

清理总览与全部清单两个空态的说明文字末尾都带括号「(进度在「空间地图」子页)」。
空间地图现在住在磁盘页;扫描进度在清理页页头的扫描按钮上就能看到。

**Desired behavior:**

两处说明去掉这个括号,只剩前半句(「扫描结束后这里出现可回收清单」「扫描结束后这里
给出可回收总量与各品类构成」)。页头的扫描状态已经承担了进度提示,不必再指路。

**Key interfaces:** 无,只改两处字符串。

**Acceptance criteria:**

- [ ] 全仓不再出现「空间地图」子页这种说法
- [ ] 清理页未扫描时两个空态的说明读起来完整
- [ ] 全量检查通过

**Out of scope:** 空态的其它文案与版式。
