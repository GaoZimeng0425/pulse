# 01 模块排行:能耗影响 / 磁盘读写 / 每进程流量

Status: ready-for-agent
分支: p1/module-rankings(worktree ../pulse-worktrees/modrank)

## 用户拍板(2026-10-17)
三个模块排行全做,子代理实现:
1. 电池页「能耗影响」排行 — rusage CPU 时间 + 唤醒(复合分,权重为约定非实测)
2. 磁盘页「读写最多」排行 — 每进程 rusage 磁盘字节差分(现有 30s 求和回退源改造为共享一趟)
3. 网络页「每进程流量」排行 — /usr/bin/nettop 子进程(Stats 同款,MIT 参考实现已验证)

## 约定
- v1 只上主窗口模块页(弹窗不放,同 dev-server 卡先例)
- 可见性门控:任何窗口可见才跑 5s/30s 低频档,否则暂停(采样成本闸门)
- 差分钳制:首次见到的 pid 记基线不出数;负差分钳 0;消失的 pid 丢弃
- 能耗权重:每唤醒折算 50ms CPU,注释言明是约定
- nettop 解析健壮性:空输出/缺列/怪进程名/非数字 pid 全部容错,测试用合成 CSV 夹具
