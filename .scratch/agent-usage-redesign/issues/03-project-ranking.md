# 03: 项目榜单——一行一项目,点开看明细

**Status:** done(2026-11-26,feat/agent-usage-redesign;装机目验归用户)

**Blocked by:** 02 (主卡;范围开关与子页结构)

**What to build:** 项目区从「每个项目一张大卡」改成一张榜单:每个项目一行——名称、
在跑标记、来源分段条、占比、消耗、环比——点一行原地展开明细(五格读数、模型构成、
来源构成、元信息)。默认按消耗从高到低列前 10 个,末行展开 / 收起。弹窗里是同一张
榜单的紧凑行。项目大卡和它的网格撤除。

**规格:** `../spec.md`「项目榜单」。

**要做的事(行为):**

- **卡**:建在「排行列表」标准件之上——卡内标题「项目 · 近 N 天」、表头
  (项目 | 占比 | 消耗 | 环比,数值列右对齐)、行尺寸走列表行两档制、卡内空态
  (沿用现有文案)。列宽是该页自己的尺寸常量(照 DESIGN.md「数值列定宽」的规矩,
  按最宽现实读数量宽),共享值委托 `RowMetrics`。
- **行**:行首文件夹图标 + 名称 + 「在跑 N」内联芯片 + 来源分段条 + 占比 + 消耗 +
  环比 + 展开箭头。整行可点,悬停有底色(排行行同款),展开时箭头翻转。
  - 图标色:今天活跃或在跑 → 该项目的主来源色(Claude 占比过半取 Claude 色,否则
    ZCode 色);否则取「停 / 未连接」的灰。
  - 分段条:定宽取 meter 条宽;长度按窗口内最大项目归一;两段 = Claude / ZCode,
    用现有分段条零件。
  - 环比文字沿用现有环比零件。
  - 紧凑档(弹窗)两行:上行 名称 + 消耗 + 箭头,下行小字「在跑 / 占比 / 环比」
    (用户 2026-11-26 拍板;一行五列实测名称只剩约 61pt,被挤成「…」)。
- **明细**(展开后,卡内抬升底、内层圆角):五格读数(Input / Output / Cache R /
  Cache W / Cache×,两端对齐)→ 模型构成(分段条 + 图例)→ 来源构成(分段条 + 图例)→
  元信息(活跃 N/M 天 · 会话数 · 请求数 · 今天活跃 / 静了 N 天)。
- **状态**:展开的项目集合由子页持有;切 7/30 保持,重进子页全部收起;
  可以同时展开多个。主窗口与弹窗都原地展开。
- **截断**:前 10 个(项目上限令牌),末行沿用现有的展开 / 收起行。
- 数据全部来自现有的项目窗口派生(排序、占比、环比、在跑数、五桶、模型与来源份额),
  不新增口径。

**落档:** `{layout.agent-project-limit}` 的说明改成榜单语义(智能体页项目榜单的默认
展示上限),从 02 挪来。

**撤除:** 项目大卡视图与它的响应式网格(新排法 `EqualHeightRow` 留在卡片家族里,
别的页会用到)。该页文件头的页面规格同步改。

**测试:** 排序、占比、环比继续由现有的项目窗口派生用例钉住(本票不新增派生);
app 侧量高用例继续钉着子页。视图靠目验。

**验收:**

- [ ] 主窗口:项目区是一张榜单,一行一个项目,列如上;没有项目大卡。
- [ ] 点一行展开明细、再点收起;可以同时展开多个;切 30 天展开状态保持。
- [ ] 占比条能看出主要来源;图标色按主来源,静了的项目是灰的。
- [ ] 超过 10 个项目时末行「显示全部(另 N 个项目)」/「收起,只看前 10 个」可用。
- [ ] 窗口内没有项目数据时是卡内空态。
- [ ] 弹窗:紧凑行,能点开,滚动与量高正常(量高用例过)。
- [ ] 无残留死代码;`sh scripts/check.sh` 全绿。

**怎么看:** 起 app → 智能体 → 消耗,滚到最下面:点任意项目行。

**Out of scope:** 点列排序、单项目下钻页;玻璃按钮、弹窗卡间距(04)。
