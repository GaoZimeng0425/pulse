**拍板(用户 2026-11-26):**

- 版式:数字卡排(今日消耗 / N 天合计 / 日均 / Claude 用量,四张平级小卡)→ 走势 | 日历
  (宽屏两列、窄了一列)→ 项目榜单。02 的「主卡」撤除。
- 配色 D(三选一,另两套是 CPU 蓝主色、网络绿主色):全部借 DESIGN.md 已有的指标色——
  页强调色 = 内存靛紫,Claude = 传感器赤陶,ZCode = CPU 蓝,模型三档 = 网络绿 / GPU 粉 /

  规矩为智能体页开例外。

**做了什么:**

  日历在卡里上下居中——两卡同高、不留大块空白。

  `AgentDeltaText` 只剩一个字号档,`.stat` 档删除;图例色点抽成 `AgentLegendSwatch`
  (走势图例、项目明细共用)。

  模型全部取 `Metric.*.accent`,不再抄 hex。
- DESIGN.md:六个智能体颜色令牌改成指标色别名;页强调色规则写明智能体页例外;加回
  走势 / 日历并排断点令牌(1024);figure-card 用途补「智能体页数字卡」;删掉只为主卡加的
