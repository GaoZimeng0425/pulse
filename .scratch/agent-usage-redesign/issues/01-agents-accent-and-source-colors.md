# 01: 换主色——青柠强调色,来源与模型按含义分色

**Status:** done(2026-11-26,feat/agent-usage-redesign;装机目验归用户)

**What to build:** 用户在 tab 条上看到的智能体图标变成青柠,智能体页两个子页里
原来所有青色的强调(卡头标题、今日数字、子页药丸、日历色阶与悬停描边、走势的线
和面、浮层色块、项目图标)一起换成青柠;项目卡上的模型构成条换成三种柔和异色,
来源构成条换成 Claude 橙、ZCode 紫。布局一个像素都不动(布局在 02–04)。

**规格:** `../spec.md`「颜色」一节。取值以原型 `?mode=c` 为准(浅 / 深):

| 令牌 | 浅 | 深 | 含义 |
|---|---|---|---|
| 页面强调色 | `#5a921a` | `#a6d94a` | tab 图标、选中态、今日数字、日历色阶 |
| 来源 · Claude | `#c9622f` | `#e8946a` | Claude 的来源色 |
| 来源 · ZCode | `#6a4fe0` | `#8f7cf5` | ZCode 的来源色 |
| 模型一 / 二 / 三 | `#1a78bd` / `#bd3a7c` / `#93730f` | `#58a8e8` / `#e070a8` / `#cfab4a` | 模型分布的分区色 |

**要做的事(行为):**

- **页面强调色成令牌**:视图层的颜色令牌表(`Surface`)新增智能体页强调色,
  浅深双值;智能体页共用的那个全局强调色常量改为取它,引用面不动。
- **tab 取色归一口**:现在两个 tab 条(主窗口药丸条、弹窗图标条)各自从
  「tab → 指标」的映射里取指标色,药丸条还对清理页做了一次特判。改成两个条
  都走同一个取色口:智能体 tab 取智能体页强调色,清理 tab 取清理页强调色,其余取
  指标色。「tab → 指标」的映射本身不动,给它补一句说明(哪些 tab 的颜色不走它)。
- **来源色与模型色**:`AgentModelTint` 不再借用指标色。来源取色改名 `source(_:)`
  (术语表用「来源」,不用 harness),Claude / ZCode 各取来源色;分段序号取色改名
  `model(at:)`,三档模型色,越界收第三档。调用面是项目卡的两条构成行。
- **DESIGN.md**:Colors 的 YAML 与表格加这六个令牌;原来三条「借用指标色」的
  `agent-model-*` 删掉,相关说明文字同步改。

**不要做:** 清理页「AI 模型」品类的颜色(它也借用蓝牙青,保持不动);蓝牙页;
任何布局;02–04 的内容。

**测试(app 侧 XCTest,先例 `MetricAccentTests` / `MetricTabModelTests`):**

- 六个新令牌钉死浅深数值;每个浅深互异。
- 智能体页强调色与全部指标色、清理页强调色在浅色套内、深色套内都互不相等。
- tab 取色:智能体 tab = 智能体页强调色,清理 tab = 清理页强调色,其余 tab =
  各自的指标色。
- 现有的指标色用例照旧全绿(指标色一个都没动)。

**验收:**

- [ ] 主窗口药丸 tab 与弹窗图标条:智能体选中时是青柠;切到蓝牙仍是原来的青。
- [ ] 智能体页「消耗」「会话」两个子页里没有别的青色强调。
- [ ] 项目卡:模型构成条三种新色,来源构成条 Claude 橙 / ZCode 紫,图例同色。
- [ ] 浅色、深色外观下与上表一致(测试钉死)。
- [ ] DESIGN.md 令牌表与代码一致;`sh scripts/check.sh` 全绿。

**怎么看:** 起 app → 智能体 tab:图标与页内强调变青柠;消耗页项目卡里看构成条。

**冗余搜查(立票即分诊):** 全库「青色 = 智能体」的出处只有三处——全局强调色常量、
`AgentModelTint` 的首档、tab → 指标映射里智能体指向蓝牙;`.out-of-scope/` 无同域
条目;分类 = 功能增强,无产品拍板残留(取值已由用户在原型上选定),直接
ready-for-agent。

**Blocked by:** None (can start immediately)
