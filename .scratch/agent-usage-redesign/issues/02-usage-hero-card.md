# 02: 主卡——今日大数字、折算环比、按来源分层的走势

**Status:** done(2026-11-26,feat/agent-usage-redesign;装机目验归用户)

**Blocked by:** None (can start immediately;与 01 无依赖)

**What to build:** 消耗页最上面换成一张主卡:左边是今日消耗的大数字、按进度折算后
的今日环比、三格小读数;右边是近 N 天按 Claude / ZCode 分两层的面积走势。卡头右侧
是全页唯一的「7 天 | 30 天」开关。原来的「消耗总览」四张小卡和独立的「走势」卡
并入主卡后撤除。弹窗里是同一张卡的紧凑档。

**规格:** `../spec.md`「范围状态」「主卡版式」「全天等效量与今日环比」
「按来源分层的走势」「令牌表的增删」「术语表」。

**要做的事(行为):**

**派生(核心包,纯函数,时钟沿用现有注入参数)**

- 「全天等效量」抽成一个两处共用的函数:今日用量 × 86400 ÷ max(已过秒数, 6 小时)。
  日历色阶改用它(行为不变,原用例照旧全绿),今日环比也用它。
- 今日环比 =(今日全天等效量 − 昨日用量)÷ 昨日用量;昨日为 0 → 无基准。
  数字卡原有的其余派生(窗口合计与环比、日均、峰值)不变。
- 每日合计的结构补两个来源分量(Claude / ZCode),由账本行按来源分别累加,缺天补 0;
  合计仍等于两家之和。现有构造方式要兼容(老调用不改也能编过)。

**主卡(视图)**

- 卡壳走卡片家族的大卡外壳(自定内距)。卡头一行:卡头标题「消耗」+ 右侧配件槽,
  槽里是范围开关——标准药丸页签条的常规档,「7 天 | 30 天」,取页面强调色。
- 全尺寸正文:左列 200pt + 右侧撑满的走势,正文高 184,内距 16。左列从上到下:
  首行「今日消耗」(caption)与今日环比同一行(环比靠右,12 semibold;悬停说明
  写明「今天还没过完,按已过时间折算后与昨天比」)→ 今日实际用量(大数字
  figure-main)→ 读数格:`N 天合计`(副行:较上期环比)与 `日均(N 天)`(副行:
  峰值)并排,`Claude 用量` 通栏(副行:本周 · 重置)。读数用统计值零件。
  正文高 184 是用户拍板(2026-11-26):读数格带副行,标准的 176 实测放不下
  (自然高 183),不收紧间距、比标准高 8pt;DESIGN.md 大卡一条已同步。
- 紧凑档(弹窗):卡头 → 说明与大数字一行(figure-main-compact,环比在右端)→
  64 高的走势 → 三格读数一行。内距 12。图太矮,紧凑档不画半值 / 峰值刻度字。
- Claude 用量沿用现状:5 小时窗优先,缺失退本周;读不到快照如实「—」。
- 走势:两层面积 + 两条线(ZCode 在下、Claude 在上),各取来源色;今天画实际值,
  悬停标题标「今天」。悬停浮层沿用现有通用件:日期 + 总数,下面两列明细格,先两家、
  再四桶(有分项时才有)。坐标轴、标签抽稀、切范围清悬停都沿用现有做法。
- 范围是子页里唯一的状态,驱动主卡的走势和三格读数;**项目卡这一票先保持旧样子,
  但卡头自己的 7/30 开关撤掉**,标题写成「项目 · 近 N 天」,跟着主卡的范围走。
- 账本为空时整页仍是那张空态卡(不变)。子页视图的入参形状不变(量高用例钉着)。

**撤除与落档**

  页面规格里。
- 术语表(智能体账本一节)新增「来源 (Source)」「全天等效量 (Day-equivalent)」。

**测试:**

- 核心包 XCTest(先例 `AgentUsageWindowTests` / `AgentHeatScaleTests`,夹具日期从 now 推导):
  今日环比三例——过完半天、今日用量是昨天的一半 → 等于昨天 → 持平(0);
  过了 1 小时 → 按 6 小时下限折算;昨日为 0 → 无基准。每日合计的来源分量:
  两家分开累加、缺天补 0、合计 = 两家之和。
- 日历色阶原有用例不改一字,全绿(证明两处是同一个规则)。
- app 侧:子页按弹窗量法量出的高度有限(现有用例继续过)。
