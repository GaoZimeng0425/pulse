# 05: 窗口形态对齐 Vitals(总览指标卡 + 排行卡 + 主窗口工具栏)

**What to build:** 用户实机反馈"总览还是很矮,window 样式也和 vitals 官网完全不一样"。对照 SHOT1(主窗口)与 OG 左图(弹窗)整体改版:

- 采样补两项实时数据(mach API,非 P1):CPU 用户/系统拆分(每核 tick 已有,补拆分)、内存构成(host_statistics64:App/联动/压缩/缓存 + 内存压力等级)。
- 总览 = 指标卡网格(CPU / 内存:徽章+名称+chevron、34pt 圆体大数字、三列小统计、36pt 高 44 柱 strip;卡可点跳对应 tab)。
- 应用列表 = 单张排行卡(表头 应用 | CPU;行 = 图标 + 名称 + N 进程 | meter + 数值),点行展开进程表;结束整组入口保留。
- 主窗口:药丸 tab 进标题栏工具栏、齿轮在右;内容头 = 大标题 + "芯片 · N 核 · N GB";不透明窗底 + 卡底(--raised / --card 令牌)。
- 弹窗:图标 tab + "总览 / 已运行 N 天" 头 + 双列小指标卡 + "当前最忙"排行卡 + 底部操作排。
