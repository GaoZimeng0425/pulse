# 05: 空间地图轻桥——「可清理」角标 + 跳转(Q2 2026-11-04)

**What to build:** 空间地图块命中的目录若在清理白名单域内(开发者垃圾规则表:Ollama、DerivedData、Homebrew 缓存等)→ treemap 块上标「可清理」角标,点击跳开发者垃圾子页并高亮对应组(该组已有扫描结果时直接滚动定位;没扫过则引导先扫);**不命中的块不给任何可删暗示**(ADR-0008:地图永远只读,看得见 ≠ 能删)。

**用户看到什么(改前 / 改后)**:改前——地图里看到 41 GB 模型目录,唯一动作「在 Finder 中显示」然后手删,地图只诊断不开药;改后——命中白名单的块有「可清理」角标,一键跳到能动手的地方。

**接缝:** treemap 渲染已有(Canvas 命中);判定 = 白名单规则表(JunkRules)对地图节点路径的匹配,纯值可测;跳转 = 清理页壳层切子药丸 + 组定位(壳层 @State 已有先例)。

**Blocked by:** 无(可与 02/03 并行)
