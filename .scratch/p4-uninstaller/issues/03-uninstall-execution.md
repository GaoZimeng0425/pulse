# 03: 卸载执行(brew 改道 + 彻底删除 + 失败策略 + 完成反馈)

**What to build:** 卸载动作管线。默认 .app + 所选残留移废纸篓,复用一期 `CleanPlan` 确认清单弹窗。含 2026-11-04 拍板的产品口径:

- **彻底删除(Q6)**:展开区行内勾选框(措辞含「不进废纸篓,不可恢复」),默认不勾、每次展开重置;确认清单逐行红标「永久删除」;brew 勾了走 `--zap`。
- **失败策略(Q9)**:单项失败跳过继续 + 结果如实报数(与一期删除管线同口径);brew 缺失 / 命令失败 = 行内红字原因 + 本次整体中止,绝不回退文件删除。
- **brew 文案(Q11)**:徽标 hover「由 Homebrew 安装(卸载时将由它执行)」;非 brew 应用动作时刻交叉核对,归 brew 管提示改道 =「这个应用由 Homebrew 安装,建议让它卸载以保持记录一致。[取消] / [仍要直接删文件(绕过 Homebrew)]」。
- **完成反馈(Q10+Q14)**:页内完成横幅「已移入废纸篓 N 项 · X GB,失败 M 项」,不发系统通知;完成即本地移除该行 + 清掉该次消费的勾选,不触发重扫;刷新按钮保留。
- **删除前重查**:运行中 app 被拒为「先退出」(判定不缓存);灰行点卸载无操作。
- **历史**:沿用同表,去向新增「已卸载(brew,永久)」与「永久删除」。

**接缝与张力注记:**
- 永久删除是 `CleanBoundary` 新增能力(一期只有移废纸篓 / 清空废纸篓两模式);**只挂在卸载域调用链上**——p4-cleaner/08 剩余部分重开时,其「删除执行器仅两种模式」断言须按 ADR-0010 调整口径(已在其票面注记)。
- brew 交互(收据之外的 `brew uninstall` / `--zap`)走受限子进程封装:仅此两命令、超时、失败原样上报。
- v1 单 app 逐个卸载。
