# 03: 卸载执行(brew 改道 + 彻底删除 + 历史扩展)

**What to build:** 卸载动作管线。默认 .app + 所选残留一律移废纸篓,复用一期 `CleanPlan` 确认清单弹窗(逐行 = 路径 + 大小,页脚总量)。brew 徽标应用:执行时调 `brew uninstall --cask`,brew 缺失 / 失败 = 行内红字原因 + 本次整体中止,**绝不回退文件删除**。非 brew 应用点卸载时,本机有 brew 则动作时刻跑一次收据交叉核对,发现归 brew 管即提示改道(可继续可取消)。「彻底删除」勾选(brew / 非 brew 统一,默认不勾、不记忆跨次):勾 = 永久删除(brew 走 `--zap`),确认清单逐行标「永久删除」+ 明示不可恢复(ADR-0010)。删除前重查在用(判定不缓存),运行中 → 拒为「先退出」。清理历史沿用同表,去向新增「已卸载(brew,永久)」与「永久删除」。

**接缝与张力注记:**
- 永久删除是 `CleanBoundary` 新增能力(一期只有移废纸篓 / 清空废纸篓两模式);**只挂在卸载域调用链上**,清理页(开发者垃圾)不出现第三模式——p4-cleaner/08 挂起重开时,其「删除执行器仅两种模式」断言须按 ADR-0010 调整口径(已在其票面注记)。
- brew 交互(查收据之外的 `brew uninstall` / `--zap`)走受限子进程封装:仅此两命令、超时、失败原样上报,不解析 brew 其他输出。
- v1 单 app 逐个卸载,不做跨 app 多选。
