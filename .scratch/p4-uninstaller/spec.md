# P4 二期 spec:应用卸载器

Status: ready-for-agent(2026-11-04 产品拍板修订版,待票组实施)
来源:机制口径 = 2026-11-01 grill 定案(移植自 `.scratch/p4-cleaner/spec.md`「二期」节);**产品口径 = 2026-11-04 用户完整旅程梳理 + grill 15 拍修订**(本文件为唯一现行出处,与 11-01 版冲突处以本版为准,冲突两处:原「按名排序、v1 无搜索」、原「第 4 个子药丸」位置)。

## Problem Statement

一期清理器只认「目录垃圾」:能收走 DerivedData 与 node_modules,但用户想彻底送走一个 app(连同 ~/Library 里的残留)时,Pulse 仍无能为力。卸载的核心难题同一期:「敢删」——Apple 系统 app 绝不能碰,brew 装的绝不能绕过 brew 删文件,残留必须精确匹配而不是按名字广撒网;第二难题是「敢勾」——残留路径是开发者语言,普通用户看不懂就不敢动。

## 产品主线(2026-11-04 拍板 Q1)

清理功能第一主打 = **腾空间闭环**(磁盘满 → 清理 → 释放 → 磁盘卡数字下降);精确卸载是第二动机,做到敢用即可,不为它牺牲第一动机的体验。后续所有默认值取向(排序、引导、文案)以此为准。

## Solution

清理页子药丸「应用」(顺序:开发者垃圾 | 空间地图 | **应用** | 清理历史,动手门在前、档案门殿后):/Applications(含 Utilities)+ ~/Applications 的 .app 清单,**默认按占用降序、可切按名,顶部过滤搜索框**;Apple 签名系统应用永不进清单;每行 = 图标 + 名字 + .app 实际占用 + brew 徽标(解释性文案「由 Homebrew 安装」);点行展开**带人话副标的残留清单**(默认不勾 + 「全选残留」快捷);卸载默认移废纸篓并复用一期确认清单弹窗,brew 应用改道 `brew uninstall --cask`;「彻底删除」为展开区行内勾选;完成给页内横幅,失败跳过继续如实报数。

## 定案内容(11-01 机制口径,未被 11-04 修订覆盖的照旧)

- **清单与灰行**:Apple 签名的系统应用永不进清单;无权限删除的灰行标「无权限」;正在运行的灰行标「先退出」,不提供退出 / 终止按钮。在用保护与清理器同款:删除前重查、判定不缓存。v1 单 app 逐个卸载,不做跨 app 多选;不做「最近使用时间」。
- **brew 侧(机制)**:徽标判定 = 离线读 Caskroom 收据(INSTALL_RECEIPT.json 的 uninstall_artifacts 对 app 名),对不上宁可漏标不误标。执行卸载时才调 `brew uninstall --cask`;brew 缺失 / 失败 = 行内红字原因 + **本次整体中止,绝不回退文件删除**。非 brew 徽标的应用点卸载时,本机有 brew 则动作时刻跑一次交叉核对,发现归 brew 管即提示改道(可继续可取消)。brew 应用的残留候选优先取收据 zap 段声明的路径,未覆盖处落回通用位置清单。
- **删除执行(机制)**:默认 .app + 所选残留一律移废纸篓,复用清理器同款确认清单弹窗;彻底删除勾选统一走永久路径(brew 走 `--zap`)。
- **残留候选位置**(键 = bundle id 与应用名,目录名全等才命中):Application Support / Caches / Preferences(`<bid>.plist`)/ Containers / Group Containers(后缀匹配,前缀为团队 id)/ Saved Application State / HTTPStorages / WebKit / Logs / Application Scripts;LaunchAgents 恒「先检查」档;PrivilegedHelperTools 不碰(root 域)。
- **清理历史**:沿用同表,去向新增「已卸载(brew,永久)」与「永久删除」。

## 产品口径(2026-11-04 拍板 Q4–Q15)

- **Q4 残留信任三件套**:每行残留带**人话副标**(如「容器沙盒数据 · 删了下次启动重建」)+ 一句「删了会怎样」;展开区给**「全选残留」按钮**(只收通用位置,LaunchAgents 恒先检查、不进全选);**默认全不勾**立场不变;无 bundle id 的 app 如实标注「未识别,不敢猜」,不硬猜。
- **Q5 排序与搜索(推翻 11-01 两处)**:默认按占用降序、标题旁可切「按名」;顶部过滤搜索框(子页内过滤,不与主窗口全局搜索耦合)。
- **Q6 彻底删除位置**:展开区**行内勾选框**(措辞含「不进废纸篓,不可恢复」),默认不勾、**每次展开重置**(不记忆跨次);确认清单逐行红标「永久删除」二次强调;brew 勾了走 `--zap`。
- **Q9 失败策略**:执行中单项失败(EPERM 等)**跳过继续 + 结果如实报数**(与一期删除管线同口径,绝不静默);brew 命令失败仍整体中止(brew 是事务边界)。
- **Q10 完成反馈**:页内完成横幅(「已移入废纸篓 N 项 · X GB,失败 M 项」),**不发系统通知**——用户就在页面上;磁盘卡数字自然下降就是完成信号。
- **Q11 brew 文案**:解释性,不假设用户懂命令行——徽标 hover「由 Homebrew 安装(卸载时将由它执行)」;改道提示 =「这个应用由 Homebrew 安装,建议让它卸载以保持记录一致。[取消] / [仍要直接删文件(绕过 Homebrew)]」。
- **Q13 四门顺序**:开发者垃圾 | 空间地图 | 应用 | 清理历史;「应用」命名维持,tooltip 补足「卸载应用与残留」。
- **Q14 完成后反馈**:卸载完成**即本地移除该行 + 清掉该次消费的勾选**,不触发重扫;刷新按钮保留(全量重验)。

## 一期插队件(2026-11-04 拍板 Q2/Q3/Q7/Q8/Q12/Q15,另立票实施)

- **Q2 轻桥**:地图块命中的目录若在清理白名单域内 → 块上「可清理」角标,点击跳开发者垃圾子页并高亮对应组;不命中的块**不给任何可删暗示**(ADR-0008:地图永远只读)。
- **Q3 清空废纸篓提前**:从挂起的 p4-cleaner/08 摘出,排在本组票 03 之后立即补(它是腾空间闭环的必需件——清完废纸篓不空,磁盘数字不变)。
- **Q7 清理页空态引导**:维持四门不做总览页;空态引导语「先扫一遍,看看能回收多少」直达扫描按钮。
- **Q8 通知跳转**:容量类磁盘告警通知点开**跳清理页**(吞吐类不动,仍跳磁盘 tab)。
- **Q12 找回**:清理历史明细行加「在 Finder 中显示」(直达废纸篓里的去向路径并选中;「永久删除」类记录无去向,按钮不亮)。
- **Q15 历史类型标记**:历史 run 行轻量类型标记——app 卸载带应用图标、清理带垃圾桶符号;不做筛选与分页。

## 一期复用接缝(全部已落地,p4-cleaner/01–05+07+10+11)

- `CleanBoundary`(清理系统边界协议):元数据批枚举 → .app 实际占用(block 口径 + 克隆 / 硬链接去重);移入废纸篓;进程活动问询。永久删除是二期新增能力,挂同一协议。
- `CleanPlan` 确认清单弹窗、`CleanActivity` 在用保护(进程快照 `executablePath` 前缀命中 = 「先退出」判定输入)、`CleanHistory` 落库(去向枚举扩展)。
- 子药丸注册沿用清理页既有模式;图标走 AppIconCache(预栅格化先例)。

## Testing Decisions

- 夹具驱动只测外部行为(一期同款);执行管线用 spy 断言「收到哪些路径 / 是否调了 brew」,绝不真删。
- 防漂移:子页注册、收据读取、残留位置规则、历史新去向各有登记完整性测试(p2-audit 教训)。
- 稳态:卸载无常驻采集,收口票复测稳态与窗口指纹。
- **测试执行纪律(2026-11-04 用户立规)**:agent 不自行跑自动化 / e2e 测试;验证由用户发起。

## Out of Scope

跨 app 多选、「最近使用时间」;PrivilegedHelperTools 恒不碰;zap 路径家域过滤(/Library 层残留 v1 不碰,票面记档);iSurge 式 Homebrew 管理页;清理页(开发者垃圾)不加「彻底删除」;自动 / 定时任何动作;经 root 帮手。
