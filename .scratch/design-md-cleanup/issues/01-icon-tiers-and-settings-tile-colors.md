# 01: 图标分档 + 设置图标砖颜色入令牌

**What to build:** 全 app 写死尺寸的符号图标归到五档(9 / 11 / 13 / 16 / 26),
档位有单一出处;设置窗侧栏图标砖的 10 个渐变色从视图里写死的数值移到颜色令牌
的单一出处。界面上的变化只有约 14 处图标 1~2pt 的大小微调,设置图标砖外观不变。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

## Agent Brief

**Category:** enhancement

**Summary:** 图标尺寸五档单一出处并迁移约 14 处;设置图标砖渐变色入令牌。

**Current behavior:**

符号图标各处自行写死字号:同一个右箭头在总览卡与排行卡是 10pt、清理总览 11pt、
清理清单 12pt、清理应用行与清理历史 13pt;表头排序箭头 7pt;卡头副符号 10.5pt;
勾选框对勾 12pt;每应用音量卡的静音按钮随行档取 11 / 13。设置图标砖每个设置页
两个渐变色,以写死的 RGB 值定义在视图里,不在颜色令牌表内。

**Desired behavior:**

- 新增纯值的图标档位类型,五个取值 9 / 11 / 13 / 16 / 26,并提供按行的
  紧凑 / 舒适档取行首符号尺寸的入口(13 / 16)。
- 自由摆放的符号图标一律取档位:排序与展开收起的上下箭头 = 9;行内符号(行尾
  右箭头、卡头符号、小按钮里的符号、状态符号、勾选框对勾、页签条图标)= 11;
  行首类型符号 = 13(紧凑)/ 16(舒适);空态大符号 = 26。静音按钮恒 11。
- 随容器走的图标(状态芯片里的符号、类别图标瓦与设置图标砖里的符号、弹窗图标
  页签)保持现有算法不动。
- 设置图标砖的渐变色成为有名字的颜色令牌:固定色,不随明暗切换;视图只引用令牌。
- 除上述微调外外观不变。

**Key interfaces:**

- 图标档位类型:纯值,Sendable;静态常量五档 + 一个按 `compact: Bool` 取行首符号
  尺寸的函数。
- 颜色令牌的单一出处:新增设置图标砖渐变色的命名令牌(每个设置页起、止两色)。
- 各视图里符号图标的字号改引用档位。

**Acceptance criteria:**

- [ ] 单测钉死五档取值与紧凑 / 舒适档的行首符号取值
- [ ] 视图层不再有写死的符号图标字号(随容器走的除外:芯片、图标瓦、图标砖、
      弹窗图标页签)
- [ ] 设置窗视图里不再有写死的 RGB 颜色,渐变色全部来自颜色令牌单一出处
- [ ] 设置图标砖外观与改前一致
- [ ] 其余界面除图标 1~2pt 微调外无变化

**Out of scope:**

- 图标字重与符号选用
- DESIGN.md 的改写(票 07)
- 系统语义字号的 lint 规则(票 02)
