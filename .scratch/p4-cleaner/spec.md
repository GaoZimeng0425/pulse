# P4 spec:清理(删除安全骨架 + 扫描引擎 + 空间地图 + 开发者垃圾)

Status: ready-for-agent
来源:2026-10-28 /grill-with-docs 三轮拍板 + UI 原型裁决(布局 = B 分段子页 + 旭日图;原型与全部变体存档于分支 `prototype/cleaner-ui`,提交 d3652d1)+ 扫描引擎调研 `docs/research/dust-reference.md`(petal 主路径 + dust 护栏,带行号)。
词汇:本 spec 用词以根目录 `GLOSSARY.md`「清理」节为准(安全白名单 / 安全档 / 在用保护 / 排除目录 / 清理历史 / 空间地图 / 实际占用)。
参考库边界:purge-app(MIT)算法与规则表可移植,搬码注明出处;Mole(GPL-3.0)只借思路,不搬一行代码。

## Problem Statement

磁盘快满时,Pulse 是纯监视器:看得到哪个卷、哪个进程在占,但一个文件都动不了——清空间要么开 Finder 一个个点,要么装 CleanMyMac。用户是重度开发者(Xcode、Ollama、多项目构建产物、AI 编码工具遗留的 worktree),可回收垃圾以几十 GB 计;但核心难题不是"搜到"而是"敢删"——删掉正在用的项目或唯一一份的个人文件,代价远大于省下的空间。

## Solution

主窗口第 12 个药丸 tab「清理」,页内子药丸「开发者垃圾 | 空间地图 | 清理历史」。一次手动全卷扫描(低优先级、限并发、可取消、结果缓存)喂两个子页:空间地图 = 两环旭日图(v1 只读,点块下钻、面包屑返回,系统密封区折叠为不透明块);开发者垃圾 = 白名单识别出的可回收清单(默认全不勾、两档安全标签、在用保护灰行、右键排除)。一切删除移入废纸篓并逐项记清理历史;「清空废纸篓」是独立按钮(所有卷汇总 + 普通二次确认)。v1 无任何自动 / 定时清理;不经 root 帮手(ADR-0009);FDA 首版引导授予。

## User Stories

1. 作为磁盘快满的用户,我想要主窗口「清理」页一键看到哪些空间可以回收,以便不装 CleanMyMac 也能清出几十 GB。
2. 作为敢让它删文件的用户,我想要白名单外的任何东西根本不出现在清理清单里,以便我的个人文件(照片、文稿、唯一一份的备份)绝对不可能被碰到。
3. 作为敢让它删文件的用户,我想要每个可回收项带安全档标签(可安全清理 / 先检查),先检查项默认不勾,以便误删代价高的东西必须经我亲手勾选。
4. 作为用户,我想要清单默认全不勾,以便没有任何删除是我没有逐项点过头的。
5. 作为用户,我想要清理前弹确认清单(逐行 = 一个可删单元:路径 + 大小 + 档位,页脚总量),以便最后一眼看清"到底要删什么"。
6. 作为会手滑的用户,我想要一切删除只进废纸篓,以便后悔了还能恢复。
7. 作为用户,我想要「清空废纸篓」是独立按钮 + 普通二次确认,文案汇总所有卷废纸篓的项数与总量并明示永久不可恢复,以便"真释放空间"是一个我明确按下的动作。
8. 作为常驻软件的用户,我想要 v1 没有任何自动 / 定时清理,以便爆炸半径永远限定在我手动确认的那几次。
9. 作为用户,我想要每次清理记入清理历史(时间、释放量、逐项路径与去向)且永久保留,以便任何时候能回查"上次删了什么"。
10. 作为用户,我想要右键任何结果就能排除该目录,排除只收窄扫描、永不扩大,并在设置里可管理,以便某个想保留的缓存目录一刀切干净。
11. 作为开发者,我想要正在使用的项目绝不出现(终端 / 构建进程 / git 活动三路判定),且删除前重查一次、判定不缓存,以便跑着的服务不会被脚下抽掉 node_modules。
12. 作为权限敏感的用户,我想要清理全部走用户态、绝不经过 root 帮手(ADR-0009),以便 root 攻击面不因清理功能扩大。
13. 作为权限敏感的用户,我想要首版引导授予全盘访问(稳定自签身份,授权重装不丢),不授时免 FDA 子集照跑、受限类别明示,以便授权与否的后果都看得见。
14. 作为成本敏感的用户,我想要按需扫描、不做常驻索引、扫描低优先级限并发可取消,以便常驻稳态成本不因清理功能上涨。
15. 作为成本敏感的用户,我想要空间地图结果缓存到下次扫描,以便不重复烧全卷遍历。
16. 作为用户,我想要大小一律按实际占用口径(APFS 克隆与硬链接不重复计),界面标明口径,以便"回收 20 GB"是真的 20 GB。
17. 作为用户,我想要读不了的目录如实标「部分扫描」而不是显示 0 或假装完整,以便没有假数据。
18. 作为磁盘用户,我想要空间地图默认扫全卷、系统密封区折叠成一个不透明块,以便"这块盘的空间去哪了"一次看清。
19. 作为磁盘用户,我想要旭日图点块下钻、面包屑返回、悬浮看路径 + 大小 + 占整卷百分比,以便从大到小一路追到具体文件夹。
20. 作为用户,我想要空间地图 v1 只读(「在 Finder 中显示」跳走),以便「能删的地方」永远等于「白名单担保过的地方」(ADR-0008)。
21. 作为开发者,我想要全局工具缓存清单(Xcode DerivedData / DeviceSupport、Homebrew、npm、pnpm、CocoaPods、Gradle、JetBrains、VS Code / Cursor 等),以便一键看到全部工具链垃圾。
22. 作为 Docker 用户,我想要 Docker Desktop 数据(动辄几十 GB)以「先检查」档列出并写明"删除后镜像与容器全部丢失",以便这个大块头不会被当普通缓存顺手清掉。
23. 作为开发者,我想要项目产物按项目分组(node_modules / target / Pods / venv 等),以便按项目决定要不要重建。
24. 作为开发者,我想要清理功能单独一套扫描根(不复用归组的项目根),出厂给常见开发目录建议清单、由我勾选追加,以便归组配置不被清理绑死。
25. 作为开发者,我想要项目产物默认显示全部、默认按大小排序可切新旧,以便大扫除一网打尽,安全由「默认全不勾 + 在用保护」兜住。
26. 作为开发者,我想要项目年龄按项目内任何文件的最后变动(含 git 活动)算、不看产物自身时间戳,以便刚重装过依赖的老项目不被误判为新鲜。
27. 作为 AI 工作流用户,我想要 AI 模型单独分组(Ollama / LM Studio / HuggingFace 缓存等),Ollama 按内容寻址算真实可回收量(共享层不重复计),以便「删一个模型回收多少」是真数。
28. 作为 AI 编码工具用户,我想要孤儿 worktree(AI 工具遗留、git 已不登记且无终端在内)单独列出,以便 .worktrees 里的尸体被收走而活着的工作树绝不动。
29. 作为用户,我想要清理历史有独立入口可回看逐项明细,以便长期追溯。
30. 作为 Pulse 老用户,我想要清理页完全长在现有设计体系里(药丸 tab / 卡片家族 / DESIGN.md 令牌),以便它不像另一个 app 嫁接进来。

## Implementation Decisions

架构(测试接缝已与用户确认,2026-10-28):

- 照传感器家族既有插槽:PulseCore 纯值内核 + app target Live 适配器 + UI 薄壳。清理是**用户触发的按需动作**,不挂 MonitorFeatures 每轮调度、无常驻扫描;进程活动信息(在用判定输入)复用现有采样快照与项目归因的既有数据通路。
- **唯一新接缝**:「清理系统边界」协议,三件事——①枚举目录(元数据批:名 / 大小 / ino / dev / 是否目录 / dataless / 克隆私有大小);②移入废纸篓与清空废纸篓;③问"此刻哪些路径有进程活动"。真实现一个(getattrlistbulk + NSWorkspace + 采样器快照),测试一个假实现(内存夹具 + spy)。与 ProcessSource / LiveProcessSource 同款模式。
- FS 枚举 Live 实现:getattrlistbulk 一次系统调用拿整目录元数据(petal 主路径);iCloud dataless 项跳过、绝不触发回源下载;护栏照 dust(st_dev 集合剪枝防根卷 firmlink 双计、block 数虚报封顶、EINTR 重试上限、权限 / 缺失错误分类入台账不中断、进度计数);低优先级、限并发、任意时刻可取消。
- 实际占用口径:block 口径为主;(dev, ino) 硬链接后置去重;APFS 克隆按元数据私有大小单独计、共享字节不重复计;界面标口径,与「表观大小」区分。
- 白名单规则表:模式驱动(路径模式 + 安全档 + 说明文案 + 来源),未命中模式的目录不进清单。首批规则域 = 全局工具缓存目录 + 项目产物名 + AI 模型存储(含 Ollama 内容寻址 manifest 解析)+ 孤儿 worktree 判定(git worktree list 不登记 ∧ 无进程活动)。规则表数据可移植 purge-app(MIT,注明出处)。
- 在用保护:进程 cwd / argv 命中 + 构建进程特征 + git 活动三路;扫描时判定一次(影响展示),**删除前重查一次**,判定永不缓存。
- 删除执行:全部 NSWorkspace 移入废纸篓;「清空废纸篓」= 直删用户可写的废纸篓内容(~/.Trash 与各卷 .Trashes 下本用户目录),无权限项跳过并在结果里如实报数——macOS 无公开清空 API,不走 Finder 自动化(免额外 Apple Events 授权)。
- 清理历史:现有 GRDB 历史库加表(一次清理一行 run + 逐项一行 item:路径 / 大小 / 档位 / 去向),永久保留,无自动清理。
- UI:第 12 个药丸 tab(取磁盘色族;若需新色先入 DESIGN.md 表);页内子药丸「开发者垃圾 | 空间地图 | 清理历史」(原型为两子页,历史为规格新增的第三入口);确认清单、在用灰行、右键排除、「清空废纸篓」按钮在页头与扫描元信息同排——形态以原型 B 变体为准(分支 prototype/cleaner-ui);旭日图两环几何为纯值计算(树 → 弧)。菜单栏徽标与弹窗不动。
- FDA:能力检测 + 引导(直达系统设置隐私面板);未授时开发者垃圾与缓存类照扫,受 TCC 保护目录进「部分扫描」台账并在界面明示。
- 排除目录:持久化存储,只收窄;扫描与删除两处都生效。

## Testing Decisions

- 只测外部行为:喂合成文件系统夹具 → 断言产出的清单 / 空间树 / 删除计划 / 弧几何;不看内核内部结构。废纸篓执行用 spy 断言「收到了哪些路径」,绝不真删。
- 核心测试全部在 PulseCore(`swift test` 不起宿主、不起真盘扫描——测试负载最小化):白名单命中与「未识别不出现」、两档默认勾选态、在用保护三路 + 删除前重查、(dev, ino) 去重与克隆口径、st_dev 剪枝、旭日几何、清理历史 GRDB(内存库)、排除生效、多卷废纸篓汇总数。
- 防漂移(先例教训:p2-audit 容器 registry 漏登,自己上线的死功能直调 smoke 全绿假阴性):规则表加**登记完整性测试**——每条内置规则必须被至少一个正例命中,新增规则不写用例过不了测试;tab / 卡注册沿用现有注册表测试模式。
- Live 薄壳(FDA 检测、真扫描器装拆)进 PulseTests;真机全卷扫描的观感与性能(首扫时长、扫描中可取消、与 Finder 数字互证)交收口票人工目验(用户有眼睛,不循环截图)。
- 先例:GroupingEngine 合成快照测试、BadgeDisplayHysteresis 状态机测试、HistoryDatabase 内存库迁移测试。

## Out of Scope

二期批次(各批开工前单独 grill):应用缓存页、大文件 + 重复文件、应用卸载器、浏览器缓存、登录项 / 启动代理管理、Docker 悬空资源、维护任务、Intel 瘦身、TM 本地快照删除、iOS 模拟器清理、空间地图内删除(白名单识别块标出可删的 C 形态)。

明确不做:邮件附件、照片库垃圾、恶意软件扫描、浏览器隐私擦除、语言文件修剪(破坏签名)。

永久立场:自动 / 定时清理(信任建立后再议);清理经 root 帮手(ADR-0009)。
