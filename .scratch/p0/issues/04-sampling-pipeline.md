# 04: 菜单栏真数字:采样管线

**What to build:** 采样从假变真:后台 actor 以自适应节奏驱动 LiveProcessSource——弹窗关闭 5s、打开 1s;CPU 差分器用相邻两次快照的累计 CPU 时间差 ÷ 墙钟得到进程 CPU%(与活动监视器同算法);菜单栏数字 = 系统 CPU 负载(全部进程 CPU% 之和 ÷ 逻辑核数,0–100%),超过 70% 变红。差分器以"同一进程两次累计值"为夹具做纯逻辑单测。

**Blocked by:** 01, 02。

**Status:** ready-for-agent

- [ ] 菜单栏数字随真实负载跳动,与本机活动监视器读数同量级
- [ ] 跑多核死循环时数字明显攀升、超过 70% 变红,停止后回落
- [ ] 弹窗开/关时采样节奏在 1s/5s 间切换(合盖省电)
- [ ] CPU 差分纯逻辑单测:构造两次累计值,断言 CPU% 正确、核数换算正确
- [ ] 进程两次采样间消失不崩溃(差分按存活进程交集计算)
- [ ] 采样一轮的开销毫秒级(约 800 pid 量级)
