# p7-cleaner/12:Mole 条目·起步批(应用缓存类前 30 条 + 移植手法定版)

Status: ready-for-agent(2026-11-26 立)
Blocked by: 02、09、10

## 目标

把「照对齐对象的条目自己写」这套手法定下来,并落地应用缓存类的前 30 条左右(本机在场的优先)。之后每个类别按同一手法分批续开票。改之前:对齐对象 475 处清理项,我们靠搬运能到三四百条;改之后:剩下只有它有的那部分,有了一条可持续补的路。

## 范围

1. 手法(写进本票 Comments,作为后续批的模板):
   - 读对齐对象的对应条目 → 记下路径、条件(年龄 / 在用 / 是否调工具自带命令)、保护规则与事故出处;
   - 用我们的话写规则(零搬码,不逐行翻译);
   - 正例 + 条件边界用例;说明用中文;出处注明「思路来自 Mole(GPL),自行实现」。
2. 本批范围:应用缓存类,约 30 条,本机在场优先。只做「删目录 / 删文件」型;「调工具自带命令」型不在内。
3. 与已有规则重叠的合并;条目级的保护(事故教训)写进说明或保护名单。
4. 批末在票面记:本批条数、耗时体感、下批建议条数(供后续立票定粒度)。
5. 阻塞关系说明:等 02 是为了知道哪些还标着「未识别」;等 09、10 是为了避免和搬运来的条目重复。

## 验收

- [ ] 手法文档落在票面 Comments,后续批可直接照做
- [ ] 本批每条:正例、条件边界、说明、出处齐全
- [ ] 夹具:本批条目与既有规则无重复产出
- [ ] 目验:本机缓存目录下「未识别」条目进一步减少
- [ ] 票面记下条数与下批建议
