# p7-cleaner/08:卸载——系统级残留 + 输入法

Status: ready-for-agent(2026-11-26 立)
Blocked by: 05

## 目标

卸载一个应用时,它留在系统目录里的东西(系统服务与启动项、特权助手、收据声明的系统路径)出现在残留清单里,标「需要管理员权限」;勾了之后走与清理页同一套运行时授权。装在系统输入法目录里的应用也进入卸载清单。改之前:卸载后系统目录里的后台服务、特权助手继续留着、开机照常启动;改之后:它们列在残留清单里,勾了就能一起清走。

## 范围

1. 残留探测扩到系统目录,按 bundle id 与团队 id 两把键:系统服务目录、系统启动项目录、特权助手目录、Homebrew 收据 zap 段里的系统路径(此前按「只收家域」过滤掉的那部分,现在收进来并标「需要管理员权限」)。
2. 位置表补三类新位置,各带人话副标与「删了会怎样」。
3. 应用清单加收系统输入法目录;「苹果签名 / 系统自带的永不进清单」照旧;公司安全软件类永不进清单。
4. 授权:勾了系统级残留 → 卸载确认清单上这些行标「需要管理员权限」→ 执行时经 05 票的同一个接口一次授权。取消 → 这次卸载整批不动(含应用本体),勾选保留。
5. 顺序:先授权并移走系统级残留,再移应用本体与用户态残留;系统服务类只移走文件,确认清单写明「已在运行的后台进程重启后停止」。
6. 复核脚本的形状登记同步扩:服务记录、启动项记录、特权助手可执行文件、输入法应用包,各带自测。
7. Homebrew 应用的系统路径以收据为准,不绕过 Homebrew。
8. 「程序还在、但所属应用已卸载」的归属判断不在本票。
9. 清理历史的类型标记沿用(应用卸载带图标);系统级行带「需要管理员权限」。

## 验收

- [ ] 夹具:某 bundle id 的系统服务记录 / 特权助手 → 出现在该应用的残留清单,标「需要管理员权限」
- [ ] 夹具:收据 zap 段里的系统路径被收录;此前「特权助手永不探测」的断言改为「探测并标需授权」
- [ ] 夹具:输入法目录里的应用出现在应用清单,可勾选卸载;公司安全软件不出现
- [ ] 假授权接口:取消 → 应用本体与残留都不动
- [ ] 目验(用户发起、用户输密码):卸载一个带系统级组件的测试应用 → 密码框一次 → 系统目录里的残留进了废纸篓子目录

## 测试

卸载模型 spy、接缝 3、接缝 4;先例:残留探测用例、卸载执行用例。真实提权路径不进自动化测试。全量检查与真机验证由用户发起。
