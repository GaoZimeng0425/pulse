# p7-cleaner/01:底座——两个新分组 + 「需要管理员权限」「未识别」两个条目标志

Status: done(2026-11-27 合 develop @d2e52df)
Blocked by: 无(可立即开始)

## 目标

为后面的票腾位置:清理分组多「系统级」「安装包」两组;每个候选能带「需要管理员权限」「未识别」两个条目标志(GLOSSARY「条目标志」),并一路传到清单行、确认清单、清理历史。**本票不新增任何可清理的东西**——扫描结果与现在逐项一致(空组不出段、空卡不出卡)。

## 范围

1. 分组枚举加「系统级」「安装包」两个 case;组序 = 开发工具 → 浏览器 → 应用缓存 → 项目产物 → AI 模型 → 卸载残留 → 系统级 → 安装包;「按所有者分组」对新组表态 false。全部穷举 switch 由编译器强制表态,漏一处编不过。
2. 候选模型加两个条目标志:`需要管理员权限`与`未识别`,默认都不带。清单行、确认清单、清理历史行各给一个中性小标(不警示、不催促,只陈述)。
3. 总览模块卡登记两个新卡位,排在「卸载残留」之后、废纸篓卡之前;组为空时不出卡(卡的内容由 04 / 06 票填)。
4. 清理历史:条目标志随行落库并可读回;去向字段不变。
5. 防漂移:组序、组名、按所有者分组、总览卡序、子页注册的结构性断言同步。
6. 写界面前先读根目录 DESIGN.md:新小标的令牌若不在令牌表里,先补表再写码;该页怎么实现写在页面代码旁,不进 DESIGN.md。
