# p7-cleaner/03:「全选」按钮

Status: ready-for-agent(2026-11-26 立)
Blocked by: 无(可立即开始)

## 目标

全部清单页页头多一个「全选」:点一下,所有非在用条目(含「先检查」、含系统级)都勾上;仍要点确认、过确认清单;不记忆,下次扫描还是全不勾。改之前:想清干净要逐条点几十项;改之后:点两下。「一键清理安全项」一字不变。

## 范围

1. 计划生成新增预设「全选」= 全部非在用候选。与「一键清理安全项」共用同一条在用判定——在用项永不入选。
2. 页头按钮只改勾选状态,不直接弹确认;文案带数量与合计(按 DESIGN.md 的按钮规范);用户再点既有的清理入口。
3. 不记忆:勾选状态不落盘(与现状一致);总览 ↔ 清单切换不丢勾选的既有行为照旧。
4. 灰行(在用)不受影响;排除目录生效的条目不在清单里,自然不在全选范围。
5. 不动的部分:「一键清理安全项」、默认全不勾、MCP 清理工具(只安全档 + 应用内确认单)。

## 验收

- [ ] 夹具:全选后勾选集合 = 全部候选 − 在用项(含「先检查」档与带「需要管理员权限」的条目)
- [ ] 夹具:「一键清理安全项」的行为与之前逐项一致(只安全档、非在用)
- [ ] 夹具:重新扫描后勾选回到全不勾
- [ ] 确认清单与实际执行集合一致
- [ ] 目验:全部清单页点「全选」→ 全部勾上(灰行除外)→ 确认清单列出全部 → 执行集合一致

## 测试

接缝 2(计划生成);先例:一键清理安全项的计划用例、自动勾选资格判定用例。全量检查与真机验证由用户发起。
