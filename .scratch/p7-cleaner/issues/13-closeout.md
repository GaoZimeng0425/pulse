# p7-cleaner/13:收口

Status: ready-for-agent(2026-11-26 立)

## 目标

第一批全部落地后的收口:全量检查全绿、目验清单、稳态复测、旧方案里的过时说法加指向说明、本批文档提交。收口完 = 「清理向对齐对象看齐」的第一批对用户完整可见。

## 范围

1. 全量检查全绿(用户发起);核心包单测与脚本自测的计数记档。
2. 目验清单(用户):
   - 总览两张新卡(系统级、安装包)与卡序;
   - 全部清单页的「全选」;
   - 通用发现条目的「未识别」小标;
   - 安装包组;
   - 系统级组:密码框只弹一次、取消密码框整批不动、废纸篓子目录里能找回、「清空废纸篓」能处理;
   - 卸载页:多选、上次使用时间、系统级残留;
   - 空间地图的「可清理」角标没有扩大。
3. 稳态复测:清理无常驻新增,常驻成本应零变化(按既定口径)。
4. 文档收口:
   - 旧方案(p4-uninstaller、p5-cleaner、p6-cleaner)里与新决定相悖的「不做 / 不碰 / 不列」表述旁,各加一行指向 ADR-0012 / ADR-0013 与本 spec;
   - GLOSSARY、两份新 ADR、本 spec 与全部票随本批提交;
   - DESIGN.md 若有新组件规范(新小标、全选按钮、新卡)补入。
5. 并行票合并后,核对先合票新改接口的调用面——自动合并零冲突 ≠ 语义没打架。
6. 在本票 Comments 记下一步怎么立:Mole 长尾后续批(按 12 票的手法与建议条数)、命令型清理项(要先短磨一轮)。
