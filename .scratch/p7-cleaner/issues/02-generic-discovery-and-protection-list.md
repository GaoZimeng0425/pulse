# p7-cleaner/02:通用发现 + 保护名单

Status: ready-for-agent(2026-11-26 立)
Blocked by: 01

## 目标

扫描后,缓存目录、日志目录、应用数据目录里名字明确的缓存子目录这三处里,名单外的条目出现在清单中——归「先检查」、标「未识别」、并入现有分组(不新开)。正在运行的应用的条目跳过;保护名单里的永不出现。改之前:本机缓存目录有 48 项、2.2 GB 因为不在名单上既不列也清不了;改之后:它们都在清单里,由你决定勾不勾。

## 范围

1. 新增纯值判定,与卸载残留检测同形:输入扫描结果、家目录、正在运行的应用集合、安全白名单命中的路径、保护名单;输出候选。
   - 三处:缓存目录一级条目;日志目录一级条目;应用数据目录下各应用目录里名字明确的缓存子目录。
   - 「名字明确的缓存子目录」起步名单:Cache、Caches、Code Cache、GPUCache、DawnCache、GrShaderCache、ShaderCache、CachedData。实施时对照对齐对象的名单补全,只收定义上就是可重建缓存的目录;存放数据库、登录态、离线资源的目录永不收。
   - 去重:命中安全白名单(含规则表认领)的条目不重复产出;与规则表 / 项目产物 / 卸载残留路径相等或互为祖孙时让位(沿用现有让位规则)。
   - 噪音纪律沿用:零字节且非部分扫描不列。
   - 归组:三处产出的条目都归「应用缓存」组。
2. 保护名单(核心层常量单出处),首批内容:
   - 路径类:密码与密钥类(沿用现有敏感名单)、日历缓存、壁纸缩略图、接力剪贴板最近一小时内的条目、编译模型缓存、浏览器用户资料目录、邮件 / 信息 / 照片 / 备忘录的数据目录。
   - 软件类别:端点防护、设备管理、企业组网类(按 bundle id 与厂商名,至少覆盖本机在场的三家)。
   - 正在运行的应用:由在用判定动态给出,**不缓存**。
3. 在运行应用:运行中应用的 bundle id,以及它在知识库里登记的缓存目录名,对应的条目视同在用、不出现。这是进程活动源之外的新输入(运行中应用集合)。
4. 不进通用发现的位置:放着进行中工作的临时目录(如 `/private/tmp`)、用户临时与缓存目录、文稿、下载——这些只在规则表里按工具点名。
5. 清理历史:通用发现产出的条目带「未识别」标记可查。

## 验收

- [ ] 夹具:缓存目录下一个名单外的目录 → 出现,档位「先检查」,带「未识别」,归应用缓存组
- [ ] 夹具:同一路径已在规则表 → 只出规则表那一条,档位按规则表,不带「未识别」
- [ ] 夹具:条目属于正在运行的应用 → 不出现
- [ ] 夹具:条目命中保护名单任一类 → 不出现
- [ ] 夹具:应用数据目录里名字不在名单的子目录(如存放数据库的目录)不出现
- [ ] 夹具:缓存、日志、应用数据三处之外的位置里的东西不出现
- [ ] 目验:本机缓存目录下此前不列的 48 项出现在清单里,全部「先检查」+「未识别」
