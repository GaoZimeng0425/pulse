# p7-cleaner/02:通用发现 + 保护名单

Status: done(2026-11-27 合 develop @b7e4f41)
Blocked by: 无(01 已完成)

## 目标

扫描后,缓存目录、日志目录、应用数据目录里名字明确的缓存子目录这三处里,名单外的条目出现在清单中——归「先检查」、标「未识别」、并入现有分组(不新开)。正在运行的应用的条目跳过;保护名单里的永不出现。改之前:本机缓存目录有 48 项、2.2 GB 因为不在名单上既不列也清不了;改之后:它们都在清单里,由你决定勾不勾。

## 范围

1. 新增纯值判定,与卸载残留检测同形:输入扫描结果、家目录、正在运行的应用集合、安全白名单命中的路径、保护名单;输出候选。
   - 三处:缓存目录一级条目;日志目录一级条目;应用数据目录下各应用目录里名字明确的缓存子目录。
   - 「名字明确的缓存子目录」起步名单:Cache、Caches、Code Cache、GPUCache、DawnCache、GrShaderCache、ShaderCache、CachedData。实施时对照对齐对象的名单补全,只收定义上就是可重建缓存的目录;存放数据库、登录态、离线资源的目录永不收。
   - 去重:命中安全白名单(含规则表认领)的条目不重复产出;与规则表 / 项目产物 / 卸载残留路径相等或互为祖孙时让位(沿用现有让位规则)。
   - 噪音纪律沿用:零字节且非部分扫描不列。
   - 归组:三处产出的条目都归「应用缓存」组。
2. 保护名单(核心层常量单出处),首批内容:
   - 路径类:密码与密钥类(沿用现有敏感名单)、日历缓存、壁纸缩略图、接力剪贴板最近一小时内的条目、编译模型缓存、浏览器用户资料目录、邮件 / 信息 / 照片 / 备忘录的数据目录。
   - 软件类别:端点防护、设备管理、企业组网类(按 bundle id 与厂商名,至少覆盖本机在场的三家)。
   - 正在运行的应用:由在用判定动态给出,**不缓存**。
3. 在运行应用:运行中应用的 bundle id,以及它在知识库里登记的缓存目录名,对应的条目视同在用、不出现。这是进程活动源之外的新输入(运行中应用集合)。
4. 不进通用发现的位置:放着进行中工作的临时目录(如 `/private/tmp`)、用户临时与缓存目录、文稿、下载——这些只在规则表里按工具点名。
5. 清理历史:通用发现产出的条目带「未识别」条目标志(GLOSSARY「条目标志」)可查。

## 验收

- [x] 夹具:缓存目录下一个名单外的目录 → 出现,档位「先检查」,带「未识别」,归应用缓存组
- [x] 夹具:同一路径已在规则表 → 只出规则表那一条,档位按规则表,不带「未识别」
- [x] 夹具:条目属于正在运行的应用 → 不出现
- [x] 夹具:条目命中保护名单任一类 → 不出现
- [x] 夹具:应用数据目录里名字不在名单的子目录(如存放数据库的目录)不出现
- [x] 夹具:缓存、日志、应用数据三处之外的位置里的东西不出现
- [ ] 目验:本机缓存目录下此前不列的条目出现在清单里,全部「先检查」+「未识别」——**数字按实测重定,见 Comments;归用户真机验证**

**本机实测(2026-11-27,只读模拟,逐条对照实现的规则)——验收第 7 条的数字按此重定**

票面「48 项、2.2 GB」是立票前的粗测:数的是 Pulse 不认识的非苹果缓存目录,连空目录一起数。按实现规则,`~/Library/Caches` 一级 104 个目录:38 项此刻可进清单(其中一部分规则表原本就认领,按规则表列;其余是新出现的「未识别」,多是小项);8 项、约 3.1 GB 属于此刻在运行的应用(Dia 1.8 GB、MyGo Music 0.9 GB、Tern 0.2 GB 等),退出后才出现;苹果自家 48 项、约 360 MB 不列;保护名单 2 项;零字节 8 项不列。应用数据目录另有约 2.3 GB 缓存会新出现(octok 1.6 GB、bilibili 0.4 GB、Electron 0.1 GB 等;Slack 的在运行时不出现)。

**出处更正(规范轴评审查出,已回对齐对象仓库核实)**

对齐对象 #1178 是功能请求(希望清接力剪贴板缓存),不是事故;#1508 是缺陷报告(清理后日历启动即崩);#1118 是用户报告(清理后壁纸封面不见)。代码注释已如实改写。我们保护接力剪贴板缓存的依据是「同步到一半的条目不能断」,与它的出处无关。
