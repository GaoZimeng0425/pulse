# p7-cleaner/04:安装包

Status: ready-for-agent(2026-11-26 立)
Blocked by: 01

## 目标

扫描后,下载与桌面两处的 dmg、pkg、mpkg、iso、xip 列成「安装包」组,档位「先检查」,默认不勾;去向废纸篓;总览多一张「安装包」卡。改之前:下载目录里的旧安装文件没有入口;改之后:它们在清单里,勾了进废纸篓,拿错能找回。

## 范围

1. 新增匹配(扫描树内,纯值):下载、桌面两处递归;扩展名 dmg / pkg / mpkg / iso / xip,大小写不敏感;不跟随符号链接。
2. Homebrew 缓存目录已被开发工具规则整目录认领,安装包匹配在该目录下让位、不重复列(spec 原文写了三处,这一处因重叠实际不出条目——记档)。
3. 不设年龄门槛;零字节照列(沿用 2026-11-06「0 KB 也是该清的东西」口径)。
4. iCloud:未下载到本地的占位文件(无本地数据)不列;桌面若开了 iCloud 同步,删除会同步到云端——行说明里如实写一句。
5. 不碰的:安装用 zip(与普通压缩包分不清)、iCloud 云盘目录、邮件、聊天软件目录。
6. 沿用:确认清单、清理历史、排除目录、删前复核、在用保护;每行说明「下载目录 / 桌面的安装文件」。
7. 总览「安装包」卡(01 留的卡位)接上内容;下钻过滤正确。

## 验收

- [ ] 夹具:两处下五种扩展名各一 → 五条,档位「先检查」,归「安装包」组
- [ ] 夹具:zip 不列;其它目录里的 dmg 不列;符号链接不列;未下载的占位文件不列
- [ ] 夹具:Homebrew 缓存目录下不重复列
- [ ] 总览卡出现、数字与清单一致,下钻过滤正确
- [ ] 目验:下载目录里的旧 dmg 出现在清单里;勾选确认后进废纸篓、历史可见
