# p7-cleaner/07:卸载页——多选 + 上次使用时间

Status: ready-for-agent(2026-11-26 立)
Blocked by: 无(可立即开始)

## 目标

应用页可一次勾选多个应用一起卸载;每个应用显示上次使用时间(取不到显示「未知」),并能按它排序。改之前:一次只能卸一个,判断能不能删只能看占用;改之后:勾一批一起卸,哪个很久没打开了一眼能看到。

## 范围

1. 多选:点行 = 勾选 / 取消该应用(现有点行即选中本体的语义不变,只是不再互斥);展开残留仍按单个应用;动作区显示「卸载 N 个应用…」;灰行(先退出 / 无权限)不可勾。
2. 上次使用时间:取系统启动服务里的使用记录;三态——有、未知、不参与排序。排序切换在「按占用 / 按名」之外加「按上次使用」;未知的排末。
3. 确认清单:多应用合并成一张,按应用分段;每行仍带人话副标与「删了会怎样」;「彻底删除」保持逐应用的行内勾选(默认不勾、每次展开重置不变)。
4. 执行:按清单顺序逐个应用执行(沿用单应用执行器)。某个失败 → 跳过继续、如实报数;任一 Homebrew 卸载失败 → 剩余应用不再执行并如实报(沿用「Homebrew 是事务边界」的口径)。
5. 完成横幅、行移除、勾选清空、不发系统通知——全部沿用。
6. 个人数据(残留)默认不勾不变。
7. 界面动手前先读 DESIGN.md 与应用页的页面规格;新令牌先补表。

## 验收

- [ ] 夹具:勾三个应用 → 确认清单三段;执行器按清单顺序收到三次卸载请求
- [ ] 夹具:灰行不可勾;执行前变成「先退出」的应用跳过并如实报
- [ ] 夹具:中间一个失败 → 后续继续、结果如实报数;Homebrew 失败 → 剩余不执行并如实报
- [ ] 夹具:上次使用时间三态各一例;按上次使用排序时未知的排末
- [ ] 目验:应用页多选、排序切换、合并后的确认清单、完成横幅
