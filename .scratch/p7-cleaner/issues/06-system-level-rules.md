# p7-cleaner/06:系统级规则族补齐 + 总览卡

Status: ready-for-agent(2026-11-26 立)
Blocked by: 05

## 目标

「系统级」组补齐到与对齐对象借管理员权限做的那几类一致:过期的系统日志与崩溃报告、可重建的系统缓存、程序已不存在的系统服务与启动项、没被引用的第三方特权助手。总览「系统级」卡接上内容。改之前:这些位置是死角;改之后:它们出现在清单里,全部带「需要管理员权限」,由你勾、由你授权。

## 范围

1. 规则族,每条带「需要管理员权限」条目标志(GLOSSARY「条目标志」)、年龄条件(日志类 7 天,与对齐对象一致)与正例:
   - 系统日志目录下超过 7 天的日志文件
   - 系统崩溃报告目录下超过 7 天的报告(05 票已立,本票纳入族内统一管理)
   - 系统缓存目录下超过 7 天的缓存文件
   - 程序已不存在的系统服务与启动项:启动项记录指向的程序路径不存在 → 列出,档位「先检查」
   - 特权助手目录下没被任何系统服务 / 启动项引用的第三方助手 → 「先检查」
2. 对照补全:对齐对象在这几类下还有「30 天以上的内存报告、电源日志、闲置的下载临时目录」等条目,实施时逐条对照;带条件的把条件写进规则,不裸列路径。
3. 保护名单硬边界:端点防护、设备管理、企业组网类软件的系统服务、启动项、特权助手**永不列出**(用 02 票保护名单的软件类别);系统自带(苹果前缀)的系统服务与启动项永不列出。
4. 可重建系统缓存逐条有人担保:具体哪几个目录按「清了系统会自己重建、对齐对象也清」两条同时满足来定,宁缺毋滥。系统统一日志库及其索引目录**不登记**(ADR-0012)。
5. 读不到的位置(普通身份无权读大小)如实标「部分」或不出,不猜。
6. 复核脚本的形状登记同步扩:每加一类规则,脚本侧加一条形状与一条自测;规则族与脚本两边的登记由同一出处派生,或由一致性测试钉住。
7. 「程序还在、但所属应用已经卸载」的归属判断不在本票(需要推断,留待 Mole 长尾批对照)。
8. 总览「系统级」卡接内容;确认清单里这些行都带「需要管理员权限」。

## 验收

- [ ] 每条系统级规则:正例命中、年龄边界(恰好 7 天两侧)、档位正确、带「需要管理员权限」
- [ ] 夹具:公司安全软件的系统服务 / 启动项 / 特权助手不出现;系统自带的不出现
- [ ] 夹具:程序仍在的系统服务不出现;记录指向的程序不存在才出现
- [ ] 规则族与复核脚本的形状登记一致性测试通过
- [ ] 目验:扫描后「系统级」组与总览卡出现,条目全部带「需要管理员权限」

## 测试

接缝 1 + 接缝 4;先例:规则表登记用例、已装清单用例、脚本自测。全量检查与真机验证由用户发起。
