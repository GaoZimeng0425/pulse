# 03: 删前复核(全清理统一)+ 收口

**What to build:** spec §15——执行层一道闸,所有清理组白捡。

1. 扫描快照:`JunkCandidate` 补「目录自身 mtime」字段(树上节点自身 mtime,非 newestChangeEpoch);扫描时随候选带出。
2. 执行层复核(LiveCleanTrashExecutor 移废纸篓前,逐项):目标仍存在 + 目录自身 mtime == 快照;不一致 = 该项**跳过**,outcome 记 `.failed(reason: "扫描后目录有变动,已跳过——重新扫描后再清")`(如实报,历史可查)。
3. 确认 sheet 注记补一句(用户预期管理:扫描后有变动的项会被跳过)。
4. 夹具测试:变动即跳过/未变动照删/报告如实;卸载执行器(AppUninstallRunner)同闸(它有自己的 receipt 防御,补 mtime 复核一致性)。
5. 收口:全量 check(用户发起)+ 目验清单(孤儿组扫出/大卡分组/勾选两层/排除/历史找回/地图角标跳转/删前复核触发的跳过报数)。

## Comments

**2026-11-08 实施记录:**

- **快照字段落点与票面措辞的差异**:票面写「JunkCandidate 补字段」——实施为
  `SpaceNode.ownModifiedEpoch`(引擎从**父目录列表条目**带下,零额外 IO,占位节点同样带)
  → 缓存 v3(节点 flags 0b1000;**兼容读 v2**——旧缓存清单/地图照常显示,删除时无快照项
  按「缺少扫描快照」跳过,确认单提前说明)→ `JunkCandidate.modifiedAtScan`(三个规则域
  统一带出)。字段挂在节点而非只挂候选:将来任何新规则域白捡。
- **闸在执行器协议上**:`CleanTrashExecutor` 新增必填 `currentState(ofPath:)`(lstat,不跟
  符号链接)——**必填无默认实现**是刻意的:安全闸的探针漏实现应当编译失败,不是静默放行。
  判定集中在 `PreDeleteCheck`(五态:unchanged/changed/missing/noSnapshot/unreadable;
  容差 1µs 只防表示层意外)。换算单一出处 `FsTimestamp.epoch`(getattrlistbulk 与 lstat
  同一 inode 字段同一公式,Live 一致性冒烟钉住)。
- **卸载同闸的边界**:我们自己动手的**残留**批次(废纸篓/直删/brew zap 未覆盖的直删)过闸;
  **app 本体不过**(意图就是删它,自动更新刷 mtime 不该拦;它另有运行重查+收据交叉核对);
  brew --zap 声明域不过(brew 内部删,拦不到——既有注释口径不变)。残留探测顺路 lstat 一次
  拿存在性+大小+快照(原来 fileExists+stat 两次系统调用合一)。
- **夹具纪律**:TestSupport 目录夹具默认带固定 mtime,假执行器探针默认报同值——既有流程
  测试零改动(「没动过」是默认世界);复核用例逐路径改写状态。
- **测试**:核心 +12(判定表/人话全覆盖、引擎快照、三域带快照、缓存 v3 往返+v2 兼容、
  执行器闸四态混排、全跳过零调用、卸载变动跳过/brew zap 边界);app 侧 UninstallModel
  接线 1 例(变动残留跳过+批次不含)+ Live 换算一致性冒烟 1 例(合成临时目录,只读,即删)。
  过滤跑:核心 138 + app 44 全绿;全量 check 等用户发起。

**收口目验清单(起 app):**
1. 清理页确认单底部新注记(「移入前逐项复核…」);旧缓存带来的结果会多一行黄色
   「N 项来自旧版扫描、缺少快照,会被跳过」。
2. 复现跳过:扫描后去 Finder 往某个已勾选的缓存目录里加/删一个文件 → 清理 → 该项

3. 卸载:展开应用勾残留后,去动那个残留目录 → 确认卸载 → 残留行如实报跳过,app 本体照删。
